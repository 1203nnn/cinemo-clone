# 🎬 CINEMO - OTT 스트리밍 사이트 화면 구현

> 10조 **열받조** 팀 프로젝트  
> 넷플릭스 같은 OTT 서비스의 화면 시안(CINEMO)을 직접 코드로 구현한 프로젝트입니다.

## 📌 프로젝트 소개

- **프로젝트명** : CINEMO
- **기간** : [2026.10.23 ~ 2026.10.29]
- **목표** : [예: 디자인 시안을 바탕으로 반응형 OTT 메인 화면 구현, GitHub 협업 경험]
- **주요 화면** : 메인 화면, 마이페이지 [그 외 화면]

### 주요 기능

- 상단 헤더 메뉴 (로고, 카테고리 메뉴, 검색, 프로필)
- [메인 배너 / 콘텐츠 슬라이드 등]
- 마이페이지 [찜 목록, 시청 기록 등]
